Project Name: Student Management System

Description:
A desktop application developed in Java using the Swing library, designed for managing student records.
It allows adding, searching, displaying, and deleting student information, as well as recording grades per subject.
Data is stored locally using object serialization, with an option to export data to CSV format for further processing.

Key Features:
Add and delete students
Record grades per subject
Display student's average grade
Search students by index number
Export data to CSV file
Save and load data using serialization

Technologies and Tools Used:
Java SE 17
Java Swing (GUI)
Java Collections Framework (ArrayList, HashMap)
Java I/O (ObjectInputStream, ObjectOutputStream, FileWriter, PrintWriter)
JOptionPane for user dialogs
Eclipse IDE
